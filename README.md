# experiment-lab 🧪

A **private, local experimentation space** for trying anything and testing everything.

This repository is **not intended for publishing or long-term maintenance**.  
It exists purely as a scratch area for ideas, tests, learning, and exploration.

---

## 🎯 Purpose

Use this repo to:
- Test new ideas quickly
- Experiment with libraries, tools, and frameworks
- Prototype features or workflows
- Run temporary tests and benchmarks
- Store notes, drafts, and throwaway code

If it works → move it elsewhere.  
If it fails → learn and delete.

---

## 📁 Loose Structure (Optional)

```
experiment-hub/
```

Structure is **flexible**. Create folders as needed.
